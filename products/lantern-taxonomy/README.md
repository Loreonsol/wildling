# lantern-taxonomy

**Taxonomy of lanterns that light ideas instead of rooms** — metaphor only.

Offline, $0, no secrets. Never opens a network socket or ignites anything.

## Run

```bash
npm run lantern-taxonomy -- "quiet maybe" "soft assert"
node products/lantern-taxonomy/cli.mjs "a half-finished thought"
```

Pass one or more idea hints; each gets a deterministic species, fuel, habitat, lumen count, and specimen id.

## What you get

A printable field-guide page: species, fuel, habitat, metaphor lumens, specimen id, and a soft note.

## Limits

- No network
- No secrets
- Joke / ritual taxonomy, not a real light source or security tool
