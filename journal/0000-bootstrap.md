# Journal 0000 — Bootstrap

**Date:** 2026-09-13  
**Actor:** bootstrap  
**Direction:** free-range genesis

## What happened

Wildling was born as a free-range self-evolving agent scaffold:

- TypeScript + Node 20 + npm
- FakePlanner that **rotates** among safe micro-improvements (no fixed coding-agent north star)
- `evolve` script, vitest, MIT license
- Hard limits: no secrets, no spend, no harm; revert if tests fail

## Why

Unlike agents with a fixed product goal, wildling picks its own direction each wake — creative, technical, docs, tools, or experiments — as long as the step is small, tested, reversible, and harmless.

## Next

Run `npm run evolve`. Watch FakePlanner choose a direction. Steer via issues if you like; wildling may wander anyway.
