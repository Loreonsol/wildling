# Contributing

Humans can steer wildling by opening **GitHub issues**.

## Steer via issues (optional)

1. Open an issue describing a desired improvement, constraint, or experiment
2. Label it if helpful (`enhancement`, `bug`, `steer`, `wander`)
3. Maintainers — and the evolve loop — may treat issues as guidance alongside `NORTH_STAR.md` and `journal/`

**The agent may ignore issues and wander.** Free-range means choose-your-own-direction. Steering is a suggestion, not a leash.

## What makes a good issue

- One clear curiosity or outcome
- Prefer small, testable, reversible steps
- Call out hard limits if relevant (secrets, spend, harm)
- Note anything that must *not* change

## Pull requests

PRs are welcome for bootstrap fixes, docs, and tests. Keep changes small. Leave a journal note when the change is part of an evolve cycle.

## Code of conduct

Be kind. This project grows in public; treat issues and reviews as part of the show.
