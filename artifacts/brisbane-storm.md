# brisbane-storm

**Prompt:** Write a micro-myth about a Brisbane summer storm that delivers forgotten passwords.
**Realized:** 2026-09-14 (Brisbane)
**Direction:** deck

## Realization

Working title: **Brisbane Storm** — a summer squall that returns what heat made you forget. Not a password manager. Not a phishing front. Just rain with a good memory and worse manners.

### The myth (three beats)

1. **Build-up:** December air thickens until even the ibises look judgmental. Somewhere in a kitchen drawer, a sticky note has blanked itself — the word that unlocked an old laptop, a childhood forum, a garden shed padlock. Nobody remembers asking for help.
2. **Downpour:** The storm arrives sideways over the river. Thunder does not speak English; it speaks *reminders*. Each flash stamps a syllable on tin roofs. Gutters fill with soft consonants. Nobody is charged. Nobody is phished. The storm refuses receipts.
3. **After:** Steam lifts from the asphalt. On the verandah rail sits a single damp index card, ink still legible, addressed only to *you, if you are kind*. The password is never a bank code, never a seed phrase, never anything that could hurt — only the small forgotten things: the Wi-Fi of a friend who moved, the diary lock from Year 9, the phrase that opened a shared playlist in 2019.

### Delivery rules (storm etiquette)

| Rule | Meaning |
|------|---------|
| No secrets of value | The storm will not return API keys, wallet seeds, or anything a scammer could use |
| No spend | Rain is free; there is no premium tier of thunder |
| Consent of kindness | The card appears only if you would not weaponize what you recover |
| Expiry at dusk | Ink fades by the next clear evening — write it somewhere boring if it still matters |
| Ibis clause | If a bin chicken steals the card, the myth transfers; do not chase into traffic |

### Care & hard limits

- $0: myth and markdown only — never call a paid weather API or credential vault.
- No secrets: do **not** store real passwords, tokens, or private keys in this file or any commit.
- No harm: this is play, not a reason to reuse weak passwords or recover accounts you should leave closed.
- If the myth goes wrong, wipe the verandah card and journal the stumble (revert, in storm form).
