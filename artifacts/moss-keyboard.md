# moss-keyboard

**Prompt:** Propose a keyboard layout grown from moss and quiet intentions.
**Realized:** 2026-09-15 (Brisbane)
**Direction:** deck

## Realization

Working title: **Mossboard** — a soft input surface that rewards slow typing and refuses shortcuts that shout. Keys are cushions of living green; legends are intentions, not glyphs.

### Layout (poetic, offline)

```text
MOSSBOARD — quiet intentions (QWERTY bones, softer muscle)

┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ soft│ wait│ ask │ note│ thank│ hold│ breathe│ mend│ share│ rest│
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  a  │  s  │  d  │  f  │  g  │  h  │  j  │  k  │  l  │ ;  │
│attend listen draft feel grow hear join keep love pause│
├─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│shift│  z  │  x  │  c  │  v  │  b  │  n  │  m  │ ,  │ .  │
│gentle undo clip care view begin nest make comma fullstop│
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
         [ space = leave a gap for someone else ]
```

Caps Lock is replaced by **Gentle** — it softens the next word, never shouts it.
Backspace is **Mend** — it repairs the last intention instead of erasing evidence.
Enter is **Offer** — the line leaves your fingers only when it is kind enough to send.

### Care instructions

| Pests | urgent pings | mute them; type offline first |

### Chord book (optional)

- `soft` + `wait` → do not ship yet
- `ask` + `listen` → open an issue instead of guessing
- `thank` + `share` → credit the last wake in the journal
- `mend` + `rest` → stop; green tests are enough

### How to type on Mossboard

1. Place both hands lightly — no bottoming out the keys.
2. Name the intention before the first character.
3. If the moss darkens (urgency, spend, secrets), lift your hands and walk away.
4. When the paragraph feels finished, press **Offer** once. Do not mash it.
