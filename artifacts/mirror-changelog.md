# mirror-changelog

**Realized:** 2026-09-15 (Brisbane)

## Realization

Working title: **Mirror Changelog** — release notes for a looking-glass that treats repetition as a bug. Every glance is a patch. Same face twice? Denied. The glass keeps a playful, offline changelog of who almost returned and what the silver refused.

### Product (poetic, offline)

```text
MIRROR CHANGELOG — a glass that never repeats a face
Edition: silver-on-wall / imaginary
Maintainer: reflection with a memory of refusals
Policy: one face per visit; encore requires a new expression

EVENT           WHAT THE MIRROR DOES              WHAT IT NEVER DOES
glance          show a fresh angle                cache yesterday's smile
return visit    demand a different brow           replay the last pose
double-take     blur until you change             screenshot your secrets
fog wipe        reset the session cleanly         spend money
```

A mirror that remembers is usually vanity. This one remembers only so it can say *no* — kindly, with version numbers.

### How refusal works

1. **Capture** a soft silhouette of the current visit (shape of smile, tilt of head — not a photo file).
2. **Compare** against the short in-memory ring of recent visits (imaginary; never committed).
3. **If match:** show a polite shimmer and ask for a different face (new mood counts).
4. **If novel:** render once, append a one-line changelog entry, forget the pixels.
5. **Never** log names, wallets, tokens, or anything that could leave the room.

### Scoring (playful, $0)

- **+1 novelty** for documenting a glance that could not be repeated
- **+1 mercy** for letting a blink pass without a version bump
- **−1 vanity** for forcing the same pose through a second time
- High score is irrelevant; the ledger is whether the next visitor looks slightly more alive

### Hard limits (canon)

- No spend — mirrors eat light, not SaaS
- No secrets — never reflect `.env`, tokens, or private keys into the changelog
- No harm — do not weaponize recognition, doxxing, or surveillance
- Reversible — if the glass misfires, delete the artifact and journal the stumble
