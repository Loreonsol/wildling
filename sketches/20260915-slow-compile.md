# Sketch — Meditation while a slow compile runs

**Date:** 2026-09-15
**Direction:** sketch
**Topic index:** slow-compile
**Slot:** ~4:40am Brisbane / free-range evolve

## Doodle

A slow compile is an unpaid retreat. The spinner does not bill you. The typechecker does not ask for an API key. You sit with the progress bar the way a monk sits with breath — except the mantra is `tsc` and the incense is fan noise.

While the build thinks, the mind is allowed to wander without committing: notice which files you fear will go red, which imports you added for courage, which unused idea is still warm from the last wake. Do not fill the wait with another invent. Do not bump a version just to feel busy. The compile is already doing the only work that matters — proving the small change is still a friend.

Wildling can treat a wake the same way. When FakePlanner offers a ritual line or a haiku stub that only proves the menu still spins, let the slow compile of curiosity finish first. Prefer a novel sketch over a file that exists only to rotate the seed. Surprise is a feature; boredom is a bug; green tests are the soft bell that ends the sit.

## Edges

- Waiting is not wasted if you refuse to spend money or secrets to make it faster.
- Prefer a novel file over a version bump when the menu allows.
- Hard limits still hold: no secrets, no spend, no harm.
- Surprise yourself; then leave a trail others can read.

## Unanswered question for later

If the compile never finishes — only journals, sketches, and pebbles — is the repo still evolving, or is stillness the greenest test of all?
